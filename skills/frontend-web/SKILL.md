# 🎨 Frontend Web Skill

مهارة بناء وتطوير واجهات الويب الحديثة باستخدام HTML/CSS/JavaScript.

## الأهداف
- بناء واجهات متجاوبة وسهلة الاستخدام
- تطبيق مبادئ UX/UI الحديثة
- تطوير تطبيقات تعمل Offline-First
- تحسين الأداء والوصول Accessibility

## المواضيع الأساسية
### 1) HTML الدلالي
- استخدام عناصر HTML الحديثة بشكل صحيح
- هيكلة مناسبة للمحتوى
- تحسين الوصول وسهولة القراءة

### 2) CSS الحديث
- Flexbox و Grid
- CSS Variables
- Responsive Design
- Animation و Transitions
- Design Systems

### 3) JavaScript التفاعلي
- DOM Manipulation
- Event Handling
- Async/Await و Promises
- Local Storage و IndexedDB
- Service Workers

### 4) الأداء
- Lazy Loading
- Code Splitting
- Performance Profiling
- Minification و Compression

### 5) Accessibility
- WCAG Basics
- Keyboard Navigation
- Screen Reader Support
- Contrast and readability

## التطبيق في هذا المشروع
- تطبيق ويب يعمل بدون اتصال
- تصميم موحد وتخطيط متجاوب
- تخزين محلي للبيانات
- واجهات تفاعلية وقابلة للتوسع
