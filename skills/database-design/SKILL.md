# 💾 Database Design Skill

مهارة تصميم قواعد البيانات وإدارتها بشكل صحيح.

## الأهداف
- نمذجة البيانات بشكل فعّال
- اختيار النوع المناسب من قاعدة البيانات
- تحسين الاستعلامات والأداء
- الحفاظ على سلامة البيانات

## المواضيع الأساسية
- ER Modeling
- Normalization
- SQL vs NoSQL
- Indexing
- Transactions
- Backup و Recovery
- Security and access control

## أمثلة
- قاعدة بيانات للمستخدمين
- قاعدة بيانات للمهام والعمليات
- تخزين المرفقات والملفات المتصلة
