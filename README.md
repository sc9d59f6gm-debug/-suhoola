# سهولة – نظام إدارة أعمال العمليات

تطبيق ويب يعمل بدون إنترنت (HTML/CSS/JS)، وبياناته على الجهاز فقط (localStorage + IndexedDB).

## التشغيل
- محلياً: `python3 -m http.server 8000` ثم افتح `http://localhost:8000`.
- على الآيفون: ارفع المجلد على أي استضافة ثابتة تعمل بـ HTTPS (GitHub Pages مثلاً)، افتحه في Safari ثم "مشاركة ← إضافة إلى الشاشة الرئيسية". يخزّن `sw.js` الملفات للعمل دون اتصال بعد أول زيارة.

## ملاحظات
- رمز الدخول قفل بسيط وليس تشفيراً للبيانات.
- النسخة الاحتياطية (‏.json) تضم المرفقات ولا تضم الرمز ولا مفتاح API.
- التنبيهات تظهر عند فتح التطبيق فقط (قيد من المتصفحات بدون خادم).

## بنية الملفات
- `index.html` الهيكل فقط، و`app.css` التنسيق والـDesign System المشترك.
- `engine.js` محرك النماذج والسجلات (حقول، تحقق، تخزين، أرشفة، سجل زمني، حوارات).
- `sections.js` تعريفات الأقسام (Schema) — تُضاف الأقسام هنا دون تكرار الكود.
- `app.js` الواجهة العامة والمهام الدورية والتخزين والنسخ الاحتياطي، ويربط المحرك بالتخزين.
- `sw.js` و`manifest.webmanifest` للعمل دون اتصال.

## الاختبارات
شغّل خادماً محلياً على المنفذ 8765 ثم:
`SP=/tmp node tests/legacy.js` (الوظائف الأصلية) و`SP=/tmp node tests/engine.js` (محرك النماذج).
